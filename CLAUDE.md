## What This Service Does

A Go proxy service that sits between LFXv2 clients and the legacy ITX voting system. It handles:
- JWT authentication (via Heimdall JWKS)
- OAuth2 M2M authentication to ITX (private key JWT assertion)
- Terminology and ID translation (LFXv2 UUIDs ↔ LFXv1 Salesforce IDs via NATS)
- Real-time event processing (NATS JetStream KV bucket)

## Key Commands

```bash
make help            # List all available targets
make deps            # Install goa CLI + golangci-lint + go mod download
make apigen          # Regenerate API code from Goa design files (run after editing api/voting/v1/design/)
make build           # Build binary to bin/voting-api
make run             # Build and run
make debug           # Build and run with LOG_LEVEL=debug
make test            # go test ./... -v -race -timeout 5m
make lint            # Run golangci-lint
make fmt             # Format all Go files
make check           # Check formatting + lint without modifying files
```

## Running Locally (Minimal Setup)

```bash
cp .env.example .env
# Edit .env — set ITX_CLIENT_ID and ITX_CLIENT_PRIVATE_KEY (ask team member)
source .env && make run
```

See [.env.example](.env.example) for all variables with descriptions. JWT auth, NATS, and event processing are disabled by default in the example file.

The service starts on `http://localhost:8080`. Health check: `GET /health`.

To bypass ITX calls entirely during testing, mock the `VotingService` interface in `internal/domain/`.

## Architecture — Layer Rules

| Layer | Path | Rule |
|---|---|---|
| Goa DSL | `api/voting/v1/design/` | API shape only — no logic |
| Domain | `internal/domain/` | Interfaces + models — no external imports |
| Service | `internal/service/` | Business logic — depends only on domain interfaces |
| Infrastructure | `internal/infrastructure/` | External systems (ITX proxy, NATS, auth) |
| App wiring | `cmd/voting-api/` | Goa handlers, converters, main.go |
| Generated | `gen/` | **Never edit directly** — regenerated by `make apigen` |

Dependencies flow inward. Never import infrastructure from service or domain.

## Adding a New Endpoint — Checklist

1. Define the endpoint in `api/voting/v1/design/voting.go`
2. Add types in `api/voting/v1/design/types.go` if needed
3. Run `make apigen` — commit the changes in `gen/`
4. Add proxy method in `internal/infrastructure/proxy/client.go`
5. Add service method in `internal/service/voting_service.go`
6. Add request/response converters in `cmd/voting-api/service/`
7. Implement the Goa handler in `cmd/voting-api/api.go`

## Code Conventions

- **Formatting**: `gofmt` / `goimports` — run `make fmt` before committing
- **Linting**: `golangci-lint` with config in `revive.toml` — run `make lint`
- **Logging**: Use `slog` — never `fmt.Println` or `log.Printf`
- **Errors**: Use the `ErrorType` enum pattern in `internal/domain/`
- **Comments**: All exported functions and types must have doc comments
- **License header**: Every new source file must start with:
  ```
  // Copyright The Linux Foundation and each contributor to LFX.
  // SPDX-License-Identifier: MIT
  ```
  (Use `#` prefix for YAML/Makefile/shell files)

## Environment Variables (Summary)

| Variable | Default | Notes |
|---|---|---|
| `PORT` | `8080` | HTTP port |
| `LOG_LEVEL` | `debug` | `debug\|info\|warn\|error` |
| `JWKS_URL` | `http://heimdall:4457/.well-known/jwks` | Skip with `JWT_AUTH_DISABLED_MOCK_LOCAL_PRINCIPAL` |
| `JWT_AUTH_DISABLED_MOCK_LOCAL_PRINCIPAL` | `""` | Set to any string to bypass JWT auth locally |
| `ITX_BASE_URL` | `https://api.dev.itx.linuxfoundation.org/` | |
| `ITX_CLIENT_ID` | **(required)** | Ask team member |
| `ITX_CLIENT_PRIVATE_KEY` | **(required)** | RSA PEM key — ask team member |
| `NATS_URL` | `nats://nats:4222` | Disable with `ID_MAPPING_DISABLED=true` |
| `ID_MAPPING_DISABLED` | `false` | Set `true` for local dev without NATS |
| `EVENT_PROCESSING_ENABLED` | `true` | Set `false` for local dev without NATS |

Full env var table: [README.md#configuration](README.md#configuration)
